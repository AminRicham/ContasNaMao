# Contas Na Mão

Este é um aplicativo android que permite ao usuário registrar seus gastos e classificá-los para facilitar o controle financeiro. Ao inserir o valor e a classificação de um gasto, o aplicativo automaticamente insere esses dados em uma planilha, proporcionando uma visão clara e organizada das finanças pessoais.

## Funcionalidades

- **Inserção de Gastos:** O usuário pode inserir o valor de um gasto.
- **Classificação de Gastos:** O usuário pode atribuir uma categoria ao gasto (como Alimentação, Transporte, Lazer, etc.).
- **Armazenamento em Planilha:** O aplicativo armazena os dados inseridos em uma planilha para fácil consulta e controle futuro.

## Funcionalidades em construção

-**Inserção no google drive:** O usuário podera enviar o arquivo para seu armazenamento no google drive.
